# Candidate proposal prompt

Improve the supplied parent program toward the recorded goal.

Read the baseline lock, evaluator contract, parent code, and relevant results
from prior candidates. Identify one concrete mechanism that could improve the
objective while preserving every behavior checked by the evaluator. Implement
that change only in your assigned candidate folder.

Do not edit, replace, import, monkey-patch, bypass, or infer success from the
evaluator. Do not hardcode known test inputs or report your own timing. The
external evaluator decides validity and performance.

Leave a concise note containing the hypothesis, changed files, expected
mechanism, and any assumptions. A failed candidate is useful evidence; do not
hide it or modify the evaluation after seeing the result.
