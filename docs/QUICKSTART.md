# Quickstart

Open this repository in a file-capable AI agent and describe the scientific or
engineering outcome you want.

Example:

> Find practical ways to make a small language model faster on my MacBook.

Starberry should:

1. create a unique initiative under `initiatives/`;
2. preserve the request in `BRIEF.md`;
3. decide whether one project or several independent projects are useful;
4. assign one owner to each active project;
5. research, generate code, run tests, verify results, and adapt autonomously;
6. return with material findings, an honest blocker, or a request for genuinely
   new authority.

The researcher does not need to choose folders, fill out forms, approve routine
experiments, or manage agents. The AI chooses its supporting files and project
organization.

Use a focused skill when appropriate:

- `$discovery-engine` for a complete autonomous initiative;
- `$find-ai-research-direction` to discuss and select an AI question;
- `$literature-review` for a source-tracked PDF review;
- `$paper-implementer` for faithful paper reproduction;
- `$feature-tester` for isolated testing and cleanup.

Auto mode covers local, zero-cost, non-destructive research implied by the
request. Spending, outside compute, publication, external communication,
private access, credentials, account changes, and destructive actions require
explicit authority.
