# Literature review loop

A review begins from the initiative brief and a decision-relevant question.
The worker chooses a transparent scope, cutoff, search strategy, inclusion
logic, and stopping rule before searching. It preserves exact queries, source
identifiers, dates, screening decisions, access limitations, and claim-level
support in whatever project-local structure is clearest.

The review ends with a verified PDF and an inspectable evidence trail. Missing
or conflicting evidence is reported directly. A literature review maps existing
knowledge; it does not silently become an experiment or claim novelty.
