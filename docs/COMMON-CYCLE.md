# Common research cycle

Use this as judgment guidance, not a required procedure:

```text
brief
→ evidence and literature
→ independently useful question
→ cheapest informative test
→ inspected result
→ verification when warranted
→ deepen, branch, pivot, synthesize, or stop
```

Before observing a decisive result, state what would count as success, failure,
or inconclusive evidence in whatever form fits the project. Preserve methods,
raw outputs, deviations, and negative results. Change mechanism after repeated
stale work instead of endlessly tuning the same idea.
