# Autonomous loop

Auto mode is the normal Open Discovery experience. One human brief may expand
into many AI-generated projects without routine interruption.

The initiative leader continuously chooses the next useful action from
completed evidence. It may start literature work, create a project, run a cheap
screen, deepen a promising result, request independent verification, pivot to a
different mechanism, synthesize the portfolio, or close exhausted work.

Autonomy is bounded by the brief and human authority. It does not permit
spending, outside compute, publication, external communication, private access,
credentials, account changes, or destructive actions.

The loop should stop when the requested outcome is delivered, no useful
question remains, the evidence is honestly inconclusive, the next action needs
new authority, or the human says stop.
