# Current product focus

Open Discovery is building two automation loops connected by one durable
research record.

## 1. Literature review loop

Purpose: determine what credible evidence already exists, where sources agree,
where they conflict, and which uncertainty remains worth testing.

Output: a frozen scope, reproducible search log, source-level evidence table,
honest synthesis, and one evidence-based next decision.

## 2. Experiment loop

Purpose: create new evidence through the smallest approved test that can change
the project decision.

Output: a frozen protocol, preserved inputs and outputs, decision-rule check,
negative or positive result, and one evidence-based next decision.

## 3. Shared research memory

Both loops update the same project files. This layer records:

- the question and current baseline;
- what is observed, inferred, disputed, and unknown;
- sources, experiments, failures, and limitations;
- human approvals and AI authority boundaries;
- the strongest current finding and exact resume point.

This memory is the control layer. It is not a third automation product.

## Full Auto paper mode

When requested, the agent may carry one project from question selection through
literature review, experiments or proof work, preserved findings, and a
finished paper. Full Auto uses the same evidence and state records; it is not a
shortcut around them.

## Current research modes

Version 0.2 develops specialized tools for:

- AI and machine learning;
- mathematics;
- biology.

The shared loop may still record other research, but Open Discovery should not
claim field-specific support until a corresponding mode guide exists.

## Not now

Version 0.2 does not focus on grant writing, journal submission, researcher
social networks, dashboards, autonomous publication, laboratory robotics, or
general-purpose project management.

Reports and papers may be generated from preserved evidence, but writing must
not replace source review or experiment validation.
