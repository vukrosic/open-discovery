# Experiment contract

Open Discovery keeps the shared experiment contract deliberately small. Every
experiment only needs to answer these seven questions:

1. **What question is being asked?**
2. **What inputs and permissions exist?**
3. **What can be changed?**
4. **How is success measured?**
5. **What evidence was produced?**
6. **What is missing or uncertain?**
7. **When must the agent stop and ask a human?**

These questions are the only common requirements. An experiment may use any
domain-specific files, tools, methods, metrics, or workflow it needs. We are
standardizing the questions that make an experiment understandable and honest,
not forcing every experiment to have the same internal design.
