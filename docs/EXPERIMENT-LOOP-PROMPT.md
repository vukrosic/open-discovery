# Experiment loop prompt

```text
Continue this Open Discovery initiative autonomously. Read the human brief and
the owning project's evidence, choose the cheapest useful next test, state its
decisive criteria before observing results, run it inside existing authority,
inspect the artifacts, preserve failures and deviations, and use the result to
deepen, branch, pivot, synthesize, or stop. Choose whatever project-local files
and code make the work clear and reproducible.
```
