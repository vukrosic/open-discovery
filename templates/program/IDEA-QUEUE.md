# Program idea queue

This is a lightweight list of possible independent explorer projects. The
direction leader may start, pause, reject, or replace ideas within existing
authority. Ask the human only when an idea needs new authority.

Keep enough selected projects available to sustain the useful explorer pool
without inventing busywork. Completed evidence, not a fixed idea quota,
determines what should run next.

## State definitions

- **Proposed:** worth considering.
- **Selected:** chosen by the leader for exploration.
- **Rejected:** evidence or direction does not justify pursuing it.
- **Parked:** deliberately deferred.
- **Queued:** selected, but waiting for a real dependency or resource.
- **Running:** its assigned research task is active.
- **Completed:** the project's frozen completion rule passed.
- **Inconclusive:** work finished without resolving the question.
- **Blocked:** work cannot continue inside current authority or resources.
