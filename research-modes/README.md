# Research modes

Open Discovery currently focuses on three fields:

1. [AI and machine learning](AI-MACHINE-LEARNING.md)
2. [Mathematics](MATHEMATICS.md)
3. [Biology](BIOLOGY.md)

Every project uses the same question, literature, idea, experiment, evidence,
and findings loop. The mode guide adds the field-specific checks and records
needed to make that loop useful.

## Shared research tools

- **Question shaper:** turn a topic into one uncertainty that changes a
  decision or belief.
- **Literature mapper:** preserve searches, screen sources, compare claims, and
  identify an evidence gap.
- **Idea generator:** recommend one next direction grounded in completed
  evidence.
- **Protocol freezer:** define the method, baseline, evidence, and decision rule
  before seeing the result.
- **Evidence ledger:** preserve observations, sources, outputs, failures, and
  limitations.
- **Counterexample search:** actively look for cases that weaken the current
  claim.
- **Result writer:** turn the durable record into a short report or paper
  without overstating what was established.

When a project spans fields, choose one primary mode and record any secondary
mode in `PROJECT.md`. Apply both guides only where they are relevant.
